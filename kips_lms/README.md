# SkillRise LMS Starter

A functional front-end prototype inspired by large online learning portals.

## Included Features

- Home page
- Course catalogue and search
- Student dashboard
- Progress bars
- Course lesson modal
- Demo quiz
- Certificate preview
- Admin dashboard demo
- Mobile responsive design
- SQL database schema
- Laravel API planning document

## Run the Demo

1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. No server installation is required for this prototype.

## Production Upgrade Plan

For a full live LMS, connect this interface to:

- Laravel REST API
- MySQL database
- React or Next.js frontend
- Laravel Filament admin panel
- Private video hosting such as Bunny Stream or Vimeo
- Email/SMS notification service
- QR certificate verification
- Secure login, roles and permissions

## Important

This is a working UI prototype and technical starter package, not yet a production-hosted portal.
